## FinanceBench (open-source sample)

| Field | Value |
| --- | --- |
| Source | Patronus AI, https://github.com/patronus-ai/financebench |
| Paper | Islam et al., *FinanceBench: A New Benchmark for Financial Question Answering*, 2023 |
| Version | Git commit `cc39aeb4afdf33909ee1412188bf89035950c2eb` |
| Files | `data/financebench_open_source.jsonl` (150 questions), SHA-256 `a5a2aa673e573e55675fc3c0f9aa38c1cf59d2abc91edb077534f71f10a71877`; `data/financebench_document_information.jsonl` (361 filings), SHA-256 `1c69127783879de8cdadb159d2181f39bc3123b8e0ebf74031c3969d69189575`; `pdfs/<doc>.pdf` for the 84 filings the questions use (~160 MB) |
| Licence | The GitHub repository has no licence file (checked 2026-10-15). The Hugging Face dataset card lists **CC BY-NC 4.0** (to verify). Treat it as non-commercial: learning and evaluation only, never redistributed |
| Underlying documents | Public SEC filings and company earnings releases |
| Page numbers | `evidence_page_num` is 0-based in the source; converted to 1-based here (verified on 3M's FY2018 cash flow statement) |
| Download | `make download` (all) or `filing-assistant download --docs <names>` |

## Northwind demo filings (fictional)

Generated by `filing_assistant.demo`: a five-page 10-K with text-layer statements and an image-only exhibit that needs OCR, plus four questions with gold answers. Created at run time, no licence constraints, used by tests, `make e2e`, the image's offline build and labs.
