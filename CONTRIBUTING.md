# Contributing

Fixes and improvements are welcome, especially to the desktop and cloud labs.

1. Open an issue describing the change, or a pull request for small fixes.
2. Run `make lint test e2e` before submitting. If you touched `deploy/` or `terraform/`, say which desktop or cloud you tested on.
3. Add a line under `## [Unreleased]` in `CHANGELOG.md`.
4. Learners: please do not open pull requests with exercise solutions against starter repos.

AI agents: read [AGENTS.md](AGENTS.md) first.
